You are given CSV file(s) in the current working directory:

- riders.csv: Bike-share riders, one per row (400 rows): rider_id (six-digit id with leading zeros), display_name (person name, some with accented letters), home_district (one of 6 districts such as "Old Town"), membership (casual, monthly or annual) - these three text columns have inconsistent capital letters and stray spaces; joined_on (date as text, YYYY-MM-DD; about 2% empty), birth_year (whole number; about 4% empty), credit_balance (two decimals, can be negative; about 5% empty).
- stations.csv: Bike-share stations (48 rows, one per station): station_code (four-digit code with leading zeros, e.g. "0040"), station_name (text, a few with accented letters), district (same 6 districts as riders.csv; capital letters and spaces are inconsistent), docks (whole number), opened_on (date as text, YYYY-MM-DD).

Task: For every rider in riders.csv, find in stations.csv the station whose opened_on date is the latest one on or before the rider's joined_on date, and attach that station's docks to the rider. Keep exactly the riders' rows, one per rider; a rider with an empty joined_on, or with no station opened on or before that date, gets an empty docks value. `result` should be a table with the columns joined_on, birth_year and docks.

Requirements:
- Write a complete Python script that reads the file(s) from the current directory.
- Use only pandas, numpy and the Python standard library.
- Store the final answer in a top-level variable named `result`.
- Reply with a single Python code block.
