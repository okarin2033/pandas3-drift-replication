# Raw run records

The raw run records of the study (the `runs/` folder: about 1.4 GB in about 340,000 compressed files) will be deposited with the archived
copy of this package on Zenodo as a separate file; they are not kept in the Git repository because of their size. They are not needed to re-run the statistics: `results/per_program.jsonl` holds the per-program outcome
table that the analyzer produces from them, and every analysis reported in the article starts from it.
